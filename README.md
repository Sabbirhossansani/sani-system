# ⚡ Sabbir Hossan Sani — Personal Developer Portfolio

Welcome to the GitHub repository for my personal developer portfolio website! Built with **React 18**, **Vite**, and **Tailwind CSS**, featuring a custom **Sky Blue Glassmorphism Theme** and an **Interactive CLI Terminal Shell**.

---

## 🌟 Key Features

- **⚡ Super Fast Performance**: Powered by React 18 & Vite for instant load times and 60fps animations.
- **🎨 Sky Blue Glassmorphism Aesthetic**: Dark obsidian background with vibrant sky-blue neon accents, radial glows, and smooth blur backdrop cards.
- **📟 Interactive CLI Terminal**: In-browser command-line shell allowing visitors to type `help`, `whoami`, `skills`, `projects`, `contact`, and `clear`.
- **📱 100% Fully Responsive**: Optimized layouts across Desktop, Tablet, and Mobile devices.
- **📬 Functional Contact Hub**: Direct message form with 1-click email copy button for `sabbirsunny63@gmail.com`.

## 💻 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sabbirhossansani/Sabbirhossansani.github.io.git
   cd Sabbirhossansani.github.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
