# 🛍️ Shundor Product - Inventory & Sales Manager

A modern, fast, and automated Inventory Management & Sales Tracking Application built for **Shundor Product** ([shundorproduct.com](https://shundorproduct.com)).

---

## 🚀 Key Features

- **🔐 Protected Access:** Full-screen login overlay with customizable Username & Password and optional `Remember Me` session persistence.
- **📦 Stock & Catalog Management:** Easy product entry, cost updates (`Edit Cost`), restock increments (`+ Restock`), and low stock alerts ($\le 15$ pcs).
- **💸 Sales & Net Profit Tracking:** Quick sale recording with automatic stock deduction, revenue calculation, and net profit tracking (`Selling Price - Buying Price`).
- **📊 Real-time Dashboard & Analytics:** 7-day sales trend visual chart (powered by Chart.js), monthly revenue/profit summaries, and top-selling product rankings.
- **📄 CSV Data Export:** 1-click export of product inventory and sales history to Excel/CSV format.

---

## 🛠️ Built With

- **Frontend:** HTML5, Tailwind CSS, Lucide Icons, Chart.js, SweetAlert2
- **Backend:** Python HTTP Server (REST API)
- **Database:** SQLite3

---

## 🌐 Live Online Deployment

Hosted live on **Render.com** for access anywhere on mobile or desktop browsers.

---

## 💻 How to Run Locally

Double-click **`start_app.bat`** to launch the local server at `http://localhost:8000`.
